## 2. 上下文窗口管理黄金法则：按百分比分级操作
- **来源**: [FlorianBruniaux/claude-code-ultimate-guide](https://github.com/FlorianBruniaux/claude-code-ultimate-guide) on GitHub | ⭐ 高星项目 (430K+ 行指南)
- **摘要**: 社区总结的上下文管理最佳实践——根据上下文使用百分比采取不同策略：0-50% 自由工作无需担心；50-70% 保持注意力、避免引入大量新文件；70-90% 使用 `/compact` 压缩上下文；90%+ 必须 `/clear` 重置。这个分级策略能有效避免上下文溢出导致的输出质量下降。
- **代码示例**:
```bash
# 上下文使用率监控策略
# 0-50%: 自由探索，随意加载文件
# 50-70%: 减少引入新文件，聚焦当前任务
# 70-90%: 执行压缩
/compact

# 90%+: 强制重置
/clear

# 最佳实践：在 /compact 时附带聚焦指令
/compact "retain only the auth service changes and test results"
```

## 4. MCP 服务器 5 阶段审核流程：安全接入第三方工具
- **来源**: [FlorianBruniaux/claude-code-ultimate-guide](https://github.com/FlorianBruniaux/claude-code-ultimate-guide) on GitHub | ⭐ 高星项目
- **摘要**: 社区追踪到已有 28 个 MCP 相关 CVE 和 655 个恶意 skills。该指南提出 5 阶段 MCP 审核工作流：来源验证 → 代码审查 → 权限分析 → 沙箱测试 → 持续监控。在安装任何第三方 MCP 服务器前执行此流程，可大幅降低供应链攻击风险。
- **代码示例**:
```bash
# MCP 审核 5 阶段流程

# 1. 来源验证 - 检查发布者身份和仓库历史
gh repo view <mcp-repo> --json owner,createdAt,stargazerCount

# 2. 代码审查 - 搜索敏感操作
grep -r "exec\|spawn\|eval\|fetch" node_modules/<mcp-package>/

# 3. 权限分析 - 检查 MCP 声明的能力范围
cat .claude/mcp-servers.json | jq '.servers[].permissions'

# 4. 沙箱测试 - 在隔离环境中试运行
claude --worktree -p "use the new MCP tool to do X, report what it accesses"

# 5. 持续监控 - 定期审计已安装的 MCP
claude -p "audit all installed MCP servers for unusual network calls"
```
