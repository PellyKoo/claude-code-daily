## 1. 双模式工作流：Initializer Agent + Coding Agent
- **来源**: [HackerRank](https://x.com/hackerrank/status/2016398850265935929) on X | 🔥 高互动热帖
- **摘要**: 将长任务拆分为两个阶段：**Initializer Agent** 负责项目搭建、功能清单、Git 初始化和进度追踪；**Coding Agent** 负责阅读代码、构建功能、运行测试、提交代码和更新文档。这种分离可以避免在长时间运行中丢失上下文或浪费 token。
- **代码示例**:
```
# Phase 1: Initializer Agent
"Set up project structure, create feature list in TODO.md, init git, create tracking doc"

# Phase 2: Coding Agent
"Read TODO.md, implement feature #1, write tests, commit, update tracking doc"
```

## 2. 上下文窗口管理：30% 黄金法则
- **来源**: [shanraisshan/claude-code-best-practice](https://github.com/shanraisshan/claude-code-best-practice) on GitHub | ⭐ 55.3k stars
- **摘要**: 上下文在 300-400k token 时会出现"上下文腐烂"，模型在约 40% 上下文占用时进入"迟钝区"。社区实践建议保持上下文在 **30% 以下**以获得最佳效果。使用 `/compact` 并附带提示（hints）比自动压缩效果更好；用 `/rewind` 代替手动纠正来保持干净的上下文历史。
- **代码示例**:
```
# 主动压缩，附带提示保留关键上下文
/compact 保留数据库迁移方案和API接口设计决策

# 回退错误操作，而不是手动纠正
/rewind
```

## 5. Hooks 自动化：格式化、测试和分支保护
- **来源**: [ChrisWiles/claude-code-showcase](https://github.com/ChrisWiles/claude-code-showcase) on GitHub | ⭐ 5.9k stars
- **摘要**: 利用 `PreToolUse` 和 `PostToolUse` hooks 实现自动化工作流——每次编辑后自动运行 linter/formatter，保护主分支不被意外修改，甚至自动评估技能匹配度。还可以配置 Stop hooks 在每轮对话结束时提醒验证。
- **代码示例**:
```json
// .claude/settings.json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "command": "npx prettier --write $CLAUDE_FILE_PATH"
      }
    ],
    "PreToolUse": [
      {
        "matcher": "Bash",
        "command": "if echo $CLAUDE_TOOL_INPUT | grep -q 'git push.*main'; then exit 1; fi"
      }
    ]
  }
}
```

## 6. Miles Deutscher 的 50 条技巧精华
- **来源**: [Miles Deutscher](https://x.com/milesdeutscher/status/2014027971254952332) on X | 🔥 热门长文
- **摘要**: 经过一年的 Claude 构建实践，总结出的高频技巧精选：① 用 **Shift+Tab** 在 Opus（规划）和 Sonnet（执行）之间切换；② 在终端开 5 个 Claude 标签页并行工作，每个在独立的 git checkout 中避免冲突；③ 要求对抗性审查——让 Claude "证明这段代码能工作"并对比 main 分支差异；④ 弱方案后追问"knowing what you know now, build the elegant version"来激发更好的解决方案。

## 8. MCP 集成：打通 JIRA、Slack、数据库工作流
- **来源**: [ChrisWiles/claude-code-showcase](https://github.com/ChrisWiles/claude-code-showcase) on GitHub | ⭐ 5.9k stars
- **摘要**: 通过 `.mcp.json` 配置外部工具连接（JIRA、GitHub、Slack、Postgres），实现完整的开发闭环：Claude 可以读取工单、理解需求、实现功能、更新工单状态。还可以配置 GitHub Actions 实现自动 PR 审查、文档同步和依赖管理，估计月成本仅 $10-$50。
- **代码示例**:
```json
// .mcp.json
{
  "mcpServers": {
    "jira": {
      "command": "npx",
      "args": ["@anthropic/mcp-jira"],
      "env": { "JIRA_TOKEN": "${JIRA_TOKEN}" }
    },
    "postgres": {
      "command": "npx",
      "args": ["@anthropic/mcp-postgres", "${DATABASE_URL}"]
    }
  }
}
```
