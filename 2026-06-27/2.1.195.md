# Claude Code 2.1.195 社区实用技巧 - 2026-06-27

## 1. 动态工作流（Dynamic Workflows）：Claude Code 最强大的新功能
- **来源**: [Thariq](https://x.com/trq212/status/2061907538741006796) on X
- **摘要**: 工作流（Workflows）是自 skills 和 subagents 以来 Claude Code 最大的能力升级。在提示中提到 "workflow"，Claude 会动态创建一个严格遵循的编排计划，确保每个阶段按正确顺序执行。也可以通过 effort 菜单开启 "ultracode" 模式，让数百个并行 agent 互相检查工作。
- **代码示例**:
```
# 在提示中直接使用
> create a workflow to refactor auth module, run tests, then update docs

# 或通过 effort 菜单开启 ultracode 模式
> /effort → 选择 ultracode
```

## 2. 并行 Worktrees：同时运行 3-5 个 Claude 会话
- **来源**: [Shruti](https://x.com/heyshrutimishra/status/2018368588432978151) on X | 🔥 高互动推文
- **摘要**: Boris（Claude Code 创建者）分享的首要技巧——使用 git worktrees 同时开启 3-5 个 Claude 会话，每个会话处理不同的任务分支。这是完全不同的工作方式，也是大多数人忽略的生产力秘技。
- **代码示例**:
```bash
# 创建多个 worktree，每个跑一个独立的 Claude 会话
git worktree add ../feature-auth feature/auth
git worktree add ../feature-ui feature/ui
git worktree add ../bugfix-api bugfix/api

# 在每个 worktree 目录中启动 Claude Code
cd ../feature-auth && claude
cd ../feature-ui && claude
cd ../bugfix-api && claude
```

## 3. 关闭自动记忆（Auto Memory）以提升质量
- **来源**: [kunchenguid](https://x.com/kunchenguid/status/2067728608584675465) on X
- **摘要**: 专业技巧：禁用 Claude Code 的 "auto memory" 功能可以提升输出质量。自动记忆有时会引入不相关的上下文，影响 Claude 的判断。通过 `/memory` 命令关闭。
- **代码示例**:
```
# 在 Claude Code 中输入
/memory
# 选择 auto memory → 关闭
```

## 4. 五个改变工作方式的斜杠命令
- **来源**: [Vaibhav Sisinty](https://x.com/VaibhavSisinty/status/2067234559721361699) on X | 🔥 高互动推文
- **摘要**: 大多数人永远不会输入这些命令，但它们是 Claude Code 最强大的内置功能：`/compact`（上下文满时总结压缩）、`/loop`（定时重复执行提示）、`/schedule`（在云端按计划运行任务）、`/deep-research`（多源交叉验证的深度研究）、`/plan`（开始任务前先制定计划）。
- **代码示例**:
```
/compact          # 压缩上下文，防止 Claude 失去线索
/loop 5m /test    # 每5分钟自动运行测试
/schedule         # 创建云端定时任务（即使关机也能跑）
/deep-research    # 多源深度研究，带引用报告
/plan             # 在复杂任务前先规划
```

## 5. CLAUDE.md 是你的 Agent "宪法"
- **来源**: [The Complete Claude Code Power User Guide](https://dev.to/numbpill3d/the-complete-claude-code-power-user-guide-slash-commands-hooks-skills-more-6ep) on DEV Community
- **摘要**: 在使用任何高级功能之前，先写好 CLAUDE.md。这个文件是 agent 的"宪法"——项目如何运作的首要真相来源。每次会话 Claude 都会读取它，不需要你反复解释项目背景。把构建命令、测试方式、代码风格、架构规则都写进去。
- **代码示例**:
```markdown
# CLAUDE.md 示例
## 构建与测试
- 运行测试: `npm test`
- 单个测试: `npm test -- --grep "test name"`
- 构建: `npm run build`

## 代码风格
- 使用 TypeScript strict mode
- 组件使用函数式写法，禁止 class 组件
- 所有 API 调用必须有错误处理

## 架构
- src/api/ - API 路由
- src/components/ - React 组件
- src/utils/ - 工具函数
```

## 7. Hooks：生命周期自动化钩子
- **来源**: [Claude Code Hooks vs Slash Commands vs Skills](https://blog.laozhang.ai/en/posts/claude-code-hooks-slash-commands-skills) on LaoZhang AI Blog
- **摘要**: Hooks 是用户定义的 shell 命令或脚本，在 Claude Code 生命周期的特定节点自动执行。适用于每次都需要运行的自动化任务，比如提交前自动 lint、工具调用前检查安全性、会话结束时生成报告等。在 `.claude/settings.json` 中配置。
- **代码示例**:
```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Edit",
        "command": "echo 'Editing file: $CLAUDE_FILE_PATH'"
      }
    ],
    "PostToolUse": [
      {
        "matcher": "Bash",
        "command": "npm run lint --silent"
      }
    ]
  }
}
```
