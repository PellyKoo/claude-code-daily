# Claude Code 2.1.195 社区实用技巧 - 2026-06-28

## 1. Ultracode 模式：数百并行 Agent 互相校验工作
- **来源**: [Greg Isenberg](https://x.com/gregisenberg/status/2060072130339873093) on X | 🔥 高互动推文
- **摘要**: 在 effort 菜单中开启 "ultracode" 模式，Claude Code 会自动创建动态工作流，启动数百个并行 agent 互相检查彼此的工作。这让你能交付的工作单元从单个文件跃升到整个功能模块甚至完整项目。适合大规模重构、全面代码审查等复杂任务。
- **代码示例**:
```
# 在 Claude Code 中开启 ultracode
> /effort → 选择 ultracode

# 或在提示中直接触发
> ultracode: refactor the entire authentication system,
  update all tests, and fix any type errors
```

## 2. 工作流成本管控：避免一个提示烧掉半月额度
- **来源**: [Nate Herk](https://x.com/nateherk/status/2060780171439816984) on X | 🔥 高互动推文
- **摘要**: 一位开发者用一条工作流提示就烧掉了 $200/月订阅的一半额度。关键教训：使用工作流前先用 `/plan` 规划范围，将大任务拆分成多个小工作流分步执行，避免一次性启动过多并行 agent。用 `/compact` 定期压缩上下文也能减少 token 消耗。
- **代码示例**:
```
# ✅ 正确做法：分步执行
> /plan refactor auth module

# 确认计划后，分阶段执行
> step 1: update the data models
> step 2: update the API handlers
> step 3: update and run tests

# ❌ 错误做法：一次性提交超大任务
> ultracode: rewrite the entire backend, add tests for everything,
  update docs, fix all linting issues, and deploy
```

## 3. 50 个实战技巧精华：一年经验浓缩
- **来源**: [Miles Deutscher](https://x.com/milesdeutscher/status/2014027971254952332) on X | 🔥 高互动推文
- **摘要**: 使用 Claude 一年后总结的 50 个高频技巧，涵盖 Claude Code 的隐藏功能和提示词技巧。核心建议包括：始终以 "先读后改" 的方式工作（让 Claude 先阅读相关文件再修改）、用 `/init` 自动生成 CLAUDE.md、用 `--resume` 标志恢复上次会话、以及通过精确的文件路径引用减少歧义。
- **代码示例**:
```bash
# 恢复上次会话继续工作
claude --resume

# 自动生成 CLAUDE.md
claude /init

# 在提示中精确引用文件
> read src/auth/login.ts and src/auth/types.ts,
  then add rate limiting to the login handler
```

## 4. 声音驱动 + 无 IDE 工作流：plan.md 取代传统开发
- **来源**: [Hiten Shah](https://x.com/hnshah/status/2061881301993717886) on X | 🔥 高互动推文
- **摘要**: 一种颠覆传统的开发方式正在流行：不打开 IDE，用语音输入想法，Claude Code 把想法变成计划，计划变成持久上下文，agent 并行执行。核心流程是用 plan.md 文件管理所有任务规划，voice 模式输入需求，让 Claude Code 自主完成代码编写、测试和提交。
- **代码示例**:
```markdown
# plan.md 示例
## 目标
实现用户通知系统

## 阶段
1. [ ] 设计数据库 schema
2. [ ] 实现 WebSocket 服务
3. [ ] 创建通知组件
4. [ ] 添加端到端测试

## 约束
- 使用现有的 PostgreSQL 实例
- 通知需支持实时推送和历史查询
```
```
# 在 Claude Code 中使用
> read plan.md and start working on phase 1
```

## 5. CLAUDE.md 记忆银行系统：跨会话持久化项目知识
- **来源**: [centminmod/my-claude-code-setup](https://github.com/centminmod/my-claude-code-setup) on GitHub | ⭐ 开源模板
- **摘要**: 一套精心设计的 CLAUDE.md 记忆银行系统，通过分层结构让 Claude 在不同会话间保持项目记忆。根目录的 CLAUDE.md 放全局规则，子目录的 CLAUDE.md 放模块特定规则，配合 `.claude/settings.json` 中的自定义命令实现一键启动。每个文件控制在 200 行以内确保 Claude 可靠遵循。
- **代码示例**:
```
project/
├── CLAUDE.md              # 全局：构建命令、代码风格、架构概览
├── src/
│   ├── CLAUDE.md          # src 规则：组件规范、导入约定
│   ├── api/
│   │   └── CLAUDE.md      # API 规则：路由命名、错误处理
│   └── components/
│       └── CLAUDE.md      # 组件规则：命名、props 接口
└── .claude/
    └── settings.json      # 自定义命令和权限
```

## 6. 完整项目配置 Showcase：hooks + skills + agents + GitHub Actions
- **来源**: [ChrisWiles/claude-code-showcase](https://github.com/ChrisWiles/claude-code-showcase) on GitHub | ⭐ 开源模板
- **摘要**: 一个生产级的 Claude Code 项目配置示例，展示了如何将 hooks、skills、自定义 agents、slash commands 和 GitHub Actions 工作流整合在一起。特别值得学习的是如何用 hooks 在工具调用前后自动执行安全检查和代码质量验证，以及如何用 skills 封装团队重复使用的工作流。
- **代码示例**:
```json
// .claude/settings.json 示例
{
  "permissions": {
    "allow": ["Bash(npm test:*)", "Bash(npm run lint)"],
    "deny": ["Bash(rm -rf *)"]
  },
  "hooks": {
    "PreToolUse": [{
      "matcher": "Edit",
      "command": "npm run lint --silent -- $CLAUDE_FILE_PATH"
    }],
    "PostToolUse": [{
      "matcher": "Bash",
      "command": "npm run typecheck --silent"
    }]
  }
}
```
