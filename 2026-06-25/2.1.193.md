## 4. CLAUDE.md 中应添加的关键指令
- **来源**: [Santiago](https://x.com/svpino/status/2018682144361734368) on X | 🔥 高热度推文
- **摘要**: 在 CLAUDE.md 中添加明确的行为约束可以显著提高代码质量。核心建议包括：写代码前先描述方案并等待批准；需求模糊时主动提问澄清；任务需要跨文件修改时分阶段执行。
- **代码示例**:
```markdown
<!-- CLAUDE.md 推荐指令 -->
Before writing any code, describe your approach and wait for approval.
Always ask clarifying questions before writing any code if requirements are ambiguous.
If a task requires changes to multiple files, break it into phases.
```

## 6. CLAUDE.md 保持 200 行以内 + 使用 Rules 懒加载
- **来源**: [shanraisshan/claude-code-best-practice](https://github.com/shanraisshan/claude-code-best-practice) on GitHub | ⭐ 61.1k stars
- **摘要**: CLAUDE.md 指令超过 200 行后可靠性会下降。最佳实践是将核心规则保持精简，将特定领域的规则拆分到 `.claude/rules/*.md` 中，通过路径匹配实现按需懒加载。上下文利用率保持在 40% 以下可获得最佳性能。约 300-400k tokens 时会出现"上下文衰减"，此时应开启新会话。
- **代码示例**:
```
.claude/
├── rules/
│   ├── frontend.md      # 仅编辑前端文件时加载
│   ├── api.md           # 仅编辑 API 文件时加载
│   └── testing.md       # 仅编辑测试文件时加载
└── CLAUDE.md            # 核心规则，< 200 行
```

## 7. 用 Hooks 实现自动化：格式化、测试、提交校验
- **来源**: [ChrisWiles/claude-code-showcase](https://github.com/ChrisWiles/claude-code-showcase) on GitHub | ⭐ 6k stars
- **摘要**: 通过 `settings.json` 配置 Hooks 实现自动化工作流：PreToolUse 阻止在 main 分支上编辑；PostToolUse 自动格式化代码和运行测试；UserPromptSubmit 根据提示词分析自动推荐相关 Skills。还展示了 6 个实用 Skill 模板（测试模式、调试方法论、React UI 模式等）。
- **代码示例**:
```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Edit|Write",
        "command": "if git branch --show-current | grep -q main; then echo 'BLOCKED: no edits on main'; exit 1; fi"
      }
    ],
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "command": "npx prettier --write $CLAUDE_FILE_PATH"
      }
    ]
  }
}
```

## 8. 双记忆架构 + Statusline 成本追踪
- **来源**: [centminmod/my-claude-code-setup](https://github.com/centminmod/my-claude-code-setup) on GitHub | ⭐ 2.4k stars
- **摘要**: 提供三种 CLAUDE.md 模板（紧凑型、双记忆架构、渐进式披露），核心是"双记忆架构"：git 共享的 `CLAUDE-*.md` + 本地机器的自动记忆，确保上下文持久且可恢复。另外通过自定义 statusline 脚本实时显示模型名称、token 用量、费用和上下文窗口百分比。
- **代码示例**:
```json
{
  "statusLine": {
    "type": "command",
    "command": "~/.claude/statuslines/statusline.sh"
  }
}
```
