## 2. 5 个改变工作方式的斜杠命令
- **来源**: [Vaibhav Sisinty](https://x.com/VaibhavSisinty/status/2067234559721361699) on X | 🔥 高热度推文
- **摘要**: 大多数人从未使用过这些内置命令。`/compact` 在上下文膨胀时压缩总结、避免 Claude 丢失主线；`/review` 对当前 diff 进行代码审查；`/init` 自动生成 CLAUDE.md 项目文档；`/memory` 管理跨会话记忆。这些命令不需要额外配置，开箱即用。
- **代码示例**:
```
/compact          # 压缩上下文，保留关键信息
/review           # 审查当前 diff
/init             # 初始化 CLAUDE.md
/memory           # 查看和编辑跨会话记忆
```

## 5. CLAUDE.md 与 Hooks 的黄金搭配指南
- **来源**: [Mustafa Morbel](https://medium.com/becoming-for-better/taming-claude-code-a-guide-to-claude-md-and-hooks-ed059879991c) on Medium | 🔥 高热度文章
- **摘要**: CLAUDE.md 指令的执行可靠性约为 70%——对于代码风格偏好足够，但对于"不能推送到 main 分支"这类关键规则远远不够。Hooks 通过在 Claude 工作流的特定节点运行脚本，将合规率提升到 100%，从结构上杜绝危险操作。两者配合使用才是最佳实践。
- **代码示例**:
```json
{
  "hooks": {
    "PreToolUse": [{
      "matcher": "Bash",
      "command": "echo $CLAUDE_TOOL_INPUT | jq -r '.command' | grep -qE 'git push.*main' && echo 'BLOCKED: 禁止直接推送到 main' && exit 1 || exit 0"
    }]
  }
}
```

## 7. Claude Code Hooks 完整事件参考与 .env 保护
- **来源**: [MorphLLM](https://www.morphllm.com/claude-code-hooks) on Blog | 🔥 热门教程
- **摘要**: 详解 30 个 Hook 事件的 JSON 输入格式和退出码含义。最实用的技巧：用 PreToolUse Hook 阻止 Claude 读取 `.env` 文件，防止敏感信息泄露到上下文。还展示了如何用 Hook 实现自动代码格式化、测试运行和提交信息校验。
- **代码示例**:
```json
{
  "hooks": {
    "PreToolUse": [{
      "matcher": "Read|Edit",
      "command": "echo $CLAUDE_TOOL_INPUT | jq -r '.file_path // .path' | grep -qE '\\.env' && echo 'BLOCKED: 禁止访问 .env 文件' && exit 1 || exit 0"
    }]
  }
}
```
