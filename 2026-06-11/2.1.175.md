# Claude Code 2.1.175 社区实用技巧 - 2026-06-11

## 1. 并行 Git Worktree：最大生产力提升
- **来源**: [Boris Cherny](https://x.com/bcherny/status/2017742743125299476) on X | 🔥 高互动（Claude Code 创始人）
- **摘要**: 同时启动 3-5 个 git worktree，每个运行独立的 Claude 会话。这是 Claude Code 团队内部公认的最大生产力提升技巧。大部分团队成员使用 worktree，少数使用多个 git checkout。
- **代码示例**:
```bash
# 创建多个 worktree 并行工作
git worktree add ../feature-auth feature/auth
git worktree add ../feature-ui feature/ui
git worktree add ../bugfix-api bugfix/api
# 在每个目录中分别启动 claude
```

## 2. 动态工作流（Dynamic Workflows）：自动编排多代理
- **来源**: [Greg Isenberg](https://x.com/gregisenberg/status/2060072130339873093) on X | 🔥 高互动
- **摘要**: 在提示中输入"create a workflow"或在 effort 菜单中开启"ultracode"，Claude Code 会自动生成数百个并行代理互相校验。可以将工作单元从单个文件扩展到整个项目级别的任务。
- **代码示例**:
```
# 在 Claude Code 中直接输入：
> create a workflow to refactor the entire auth module
# Claude 会自动拆分子任务、分配代理、交叉验证结果
```

## 5. 五并行 + Opus 4.5 + Plan Mode 工作流
- **来源**: [Aakash Gupta](https://x.com/aakashgupta/status/2007347705945944153) on X | 🔥 高互动
- **摘要**: 高级用户工作流：同时运行 5 个 Claude 会话（编号标签 1-5），设置系统通知以便需要输入时提醒。始终使用 Opus 模型——虽然较慢但需要更少的引导，总体更快。先进入 Plan 模式迭代计划，确认后再让 Claude 一次性执行。
- **代码示例**:
```bash
# 终端标签 1-5 各启动一个 Claude 会话
# 每个处理不同的子任务
# 在 Claude 中：先用 /plan 模式
> /plan refactor the payment module
# 计划确认后切换到执行模式
```

## 7. CLAUDE.md 记忆库系统模板
- **来源**: [centminmod/my-claude-code-setup](https://github.com/centminmod/my-claude-code-setup) on GitHub | ⭐ 开源模板
- **摘要**: 提供了一套完整的 CLAUDE.md 记忆库（memory bank）系统模板，包括项目配置、会话启动脚本等。CLAUDE.md 是 Claude 的持久记忆，每次会话自动加载。建议保持每个文件在 200 行以内以确保可靠执行。
- **代码示例**:
```markdown
# CLAUDE.md 模板结构
## Project Context
- 项目类型、技术栈、包管理器
## Code Style
- 命名规范、测试框架、lint 配置
## Common Commands
- build / test / deploy 命令
## Architecture
- 关键目录结构说明
```
