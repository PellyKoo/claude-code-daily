# Claude Code 2.1.142 社区实用技巧 - 2026-05-14

## 1. 图片输入：截图即上下文，Debug 效率翻倍
- **来源**: [Boris Cherny](https://www.threads.com/@boris_cherny/post/DTBVlMIkpcm/) on Threads | 🔥 Claude Code 创作者亲自演示
- **摘要**: Claude Code 支持直接读取图片文件作为上下文。报错截图、设计稿、Slack 对话截图都可以直接传给 Claude，它会基于图片内容制定计划并生成代码。比手动复制粘贴错误信息更快更准确，尤其适合 UI 还原和视觉 Bug 修复。
- **代码示例**:
```bash
# 直接拖拽图片到 Claude Code 终端
# 或者用路径引用图片

> 看这个截图 ./screenshots/error.png，帮我修复这个报错

> 按照设计稿 ./design/homepage-v2.png 还原这个页面

# 支持的格式：PNG, JPG, GIF, WebP
# 图片会被自动识别和分析
```

## 2. /btw 命令：任务不中断的快速提问
- **来源**: [r/ClaudeAI](https://www.reddit.com/r/ClaudeAI/) on Reddit | 🔥 2026年3月上线后社区热议功能
- **摘要**: `/btw` 是 2026 年 3 月新增的命令，允许你在 Claude 执行任务时插入一个快速问题。答案以浮层形式弹出，不会打断当前工作流。适合在 Claude 写代码时顺便问"这个函数的参数类型是什么"或"这个包的最新版本号是多少"之类的问题。
- **代码示例**:
```bash
# Claude 正在编写代码时...
# 不需要等它完成，直接输入：

/btw TypeScript 中 Record 和 Map 的区别是什么？

# Claude 会在浮层中回答你的问题
# 同时继续执行原来的任务，互不干扰

/btw 这个项目用的是哪个版本的 React？
```

## 3. CLAUDE.md 精简法则：80 行以内效果最佳
- **来源**: [shanraisshan/claude-code-best-practice](https://github.com/shanraisshan/claude-code-best-practice) on GitHub | ⭐ 53k stars
- **摘要**: 社区实测发现 CLAUDE.md 超过 80 行后 Claude 会开始忽略部分规则，超过 200 行后遵循率显著下降。最佳实践是主文件控制在 80 行以内，用 `.claude/rules/*.md` 按需懒加载细分规则（支持 YAML frontmatter 设定 glob 匹配），把需要确定性执行的动作放到 hooks 而不是 CLAUDE.md。
- **代码示例**:
```bash
# 推荐的 CLAUDE.md 结构（控制在 80 行以内）：
# 1. 项目简述（3-5 行）
# 2. 技术栈和架构（5-10 行）
# 3. 关键命令（5-10 行）
# 4. 代码规范（10-15 行）
# 5. 注意事项（5-10 行）

# 细分规则放在 .claude/rules/ 目录：
.claude/rules/
├── frontend.md      # globs: ["src/components/**"]
├── api.md           # globs: ["src/api/**"]
├── database.md      # globs: ["**/migrations/**"]
└── testing.md       # globs: ["**/*.test.*"]

# .claude/rules/frontend.md 头部示例：
# ---
# globs: ["src/components/**/*.tsx"]
# ---
# 组件使用函数式写法，不用 class
# 样式用 Tailwind，不用 CSS modules
```

## 4. /rewind 检查点回滚：Esc 两下恢复任意状态
- **来源**: [Civil Learning](https://civillearning.medium.com/every-claude-code-hack-i-actually-use-934b2c468126) on Medium | 🔥 高阅读量实战经验帖
- **摘要**: 按两下 Esc 或输入 `/rewind` 可以调出检查点菜单，显示对话中每一步的状态快照。2026 更新后支持"仅恢复对话"和"仅恢复代码"两种模式——如果 Claude 的思路是对的但代码写错了，可以只回滚代码保留对话上下文，然后让它重新生成。
- **代码示例**:
```bash
# 方式一：按两下 Esc 键
# 弹出检查点列表：
# [1] 初始状态
# [2] 添加了用户模型
# [3] 重构了 API 路由  ← 选择这个
# [4] 修改了测试文件（当前）

# 方式二：命令行输入
/rewind

# 2026 新选项：
# > 恢复对话和代码（完整回滚）
# > 仅恢复代码（保留对话上下文）
# > 仅恢复对话（保留代码改动）
```

## 5. Hooks 自动化：取代 CLAUDE.md 中的重复指令
- **来源**: [ChrisWiles/claude-code-showcase](https://github.com/ChrisWiles/claude-code-showcase) on GitHub | ⭐ 项目配置参考模板
- **摘要**: 需要每次必须执行的动作（如格式化、lint、类型检查）应该用 hooks 而非写在 CLAUDE.md 里。Hooks 是确定性的——每次工具调用后自动触发，不依赖 Claude 是否"记得"。PostToolUse hook 可以在每次文件编辑后自动运行检查，PreCommit hook 确保提交前通过所有验证。
- **代码示例**:
```jsonc
// .claude/settings.json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "command": "npx prettier --write $CLAUDE_FILE_PATH"
      },
      {
        "matcher": "Write|Edit",
        "command": "npx eslint --fix $CLAUDE_FILE_PATH"
      }
    ],
    "PreCommit": [
      {
        "command": "npm run typecheck && npm run test -- --bail"
      }
    ]
  }
}
```

## 6. Gemini CLI 当 Claude 的跑腿小弟
- **来源**: [ykdojo/claude-code-tips](https://github.com/ykdojo/claude-code-tips) on GitHub | ⭐ 8.3k stars
- **摘要**: 社区开发者发现可以通过 MCP 或 Bash 工具让 Claude Code 调用 Gemini CLI 作为"免费劳动力"。适合让 Gemini 处理大量文本的预处理、翻译、或格式转换等不需要高推理能力的任务，主推理工作仍由 Claude 完成。这种混合方案可以显著降低 Token 成本。
- **代码示例**:
```bash
# 安装 Gemini CLI
npm install -g @anthropic-ai/gemini-cli

# 在 CLAUDE.md 中添加策略：
# 对于大文本的摘要和翻译，使用 Gemini CLI：
# gemini "翻译以下内容到中文: $(cat large_file.txt)"

# 或者在 Claude Code 中直接调用：
> 用 bash 调用 gemini 帮我把 docs/ 下所有英文文档翻译成中文

# Claude 会生成类似脚本：
for f in docs/*.md; do
  gemini "Translate to Chinese:" < "$f" > "docs/zh/$(basename $f)"
done
```

## 7. 不可访问内容的曲线救国：复制粘贴大法
- **来源**: [r/ClaudeAI](https://www.reddit.com/r/ClaudeAI/) on Reddit | 🔥 社区高频问答共识
- **摘要**: Claude Code 无法直接访问需要认证的页面（私有仓库、内部文档、部分网站）。社区总结的最佳方法：直接在浏览器中全选内容复制，粘贴到 Claude Code 对话中。比截图更好，因为文本内容可以被精确处理。对于长内容可以先存到本地文件再让 Claude 读取。
- **代码示例**:
```bash
# 方法一：直接粘贴
# 在浏览器中 Ctrl+A 全选 → Ctrl+C 复制
# 切换到 Claude Code 终端 → Ctrl+V 粘贴
> 这是我们内部 API 文档的内容：[粘贴内容]
> 帮我写一个调用这些 API 的客户端

# 方法二：保存到文件再引用
pbpaste > /tmp/api-docs.txt
> 读取 /tmp/api-docs.txt 并基于其中的 API 规范生成客户端代码

# 方法三：用 curl 保存公开页面
curl -s https://example.com/docs > /tmp/docs.html
> 读取 /tmp/docs.html 并提取关键信息
```
