## 1. Workflows：Claude Code 能力的最大升级
- **来源**: [Thariq (@trq212)](https://x.com/trq212/status/2061907538741006796) on X | 🔥 高互动讨论
- **摘要**: Workflows 被认为是自 skills 和 subagents 以来 Claude Code 最大的能力升级。它不仅能用于技术任务，还能处理非技术类工作流。通过 `export const meta` 定义多阶段工作流，可以实现并行执行、流水线处理和结构化输出。
- **代码示例**:
```javascript
export const meta = {
  name: 'review-changes',
  description: 'Review changed files across dimensions',
  phases: [{ title: 'Review' }, { title: 'Verify' }],
}
const results = await pipeline(
  DIMENSIONS,
  d => agent(d.prompt, {label: `review:${d.key}`, phase: 'Review'}),
  review => parallel(review.findings.map(f => () =>
    agent(`Verify: ${f.title}`, {phase: 'Verify'})
  ))
)
```

## 2. Skills 审计：清理无用技能提升效率
- **来源**: [Prajwal Tomar (@PrajwalTomar_)](https://x.com/PrajwalTomar_/status/2074787074641899896) on X | 🔥 高互动讨论
- **摘要**: 将技能对比文章粘贴到 Claude Code 会话中，让它列出当前已安装的所有 skills，与文章列表对比，卸载重叠的、从未触发的或过时的 skills，并安装更好的替代品。定期审计 skills 可以减少上下文噪音，提高响应质量。
- **代码示例**:
```
> 读完这篇文章，列出我当前安装的所有 skill，
  与文章对比，卸载重叠或无用的 skill，安装替代品。
```
