## 2. 动态工作流 (Dynamic Workflows)：多代理并行协作
- **来源**: [Min Choi](https://x.com/minchoi/status/2060226858994565563) on X | 🔥 新功能热议
- **摘要**: Claude Code 的 dynamic workflow 功能引发社区热议。设置 `/model` 为高级模型，将 `/effort` 设为 "ultracode"，然后在 prompt 中使用 "workflow" 关键词，Claude 会自动编写编排脚本，生成多个子代理并行工作，相互验证结果后汇报。适合大规模代码审查、重构等需要多维度并行检查的场景。注意：此功能消耗 token 极快。
- **代码示例**:
```bash
# 在 Claude Code 中
/model opus
/effort ultracode
# 然后在 prompt 中包含 "workflow" 关键词
"Create a workflow to review all changed files for bugs, performance, and security"
```

## 6. 记忆银行系统：跨会话持久化项目上下文
- **来源**: [centminmod/my-claude-code-setup](https://github.com/centminmod/my-claude-code-setup) on GitHub | ⭐ 实用模板仓库
- **摘要**: centminmod 开源了一套 Claude Code 的"记忆银行"（Memory Bank）系统。核心思路是在 `.claude/` 目录下维护结构化的上下文文件，记录项目架构决策、已知坑点、以及跨会话需要保持一致的约定。新会话启动时自动加载这些记忆文件，确保 Claude 不会在新会话中"失忆"并重复之前犯过的错误。
- **代码示例**:
```
.claude/
├── memory/
│   ├── architecture-decisions.md   # 架构决策记录
│   ├── known-issues.md             # 已知问题与坑点
│   ├── coding-conventions.md       # 编码约定
│   └── session-learnings.md        # 每次会话积累的经验
└── CLAUDE.md                       # 引用 memory/ 下的文件
```
